1. Open the deployed URL.
2. Sign in as **Kamran Qureshi** from the user list. It takes one click and no password.
3. Left rail → **Demo panel** → **Reset demo data**. This rebuilds the story with fresh timestamps, so "6 min ago" really is 6 minutes ago.

## Shortcut: the guided tour

If you would rather the software walk SBC through it, use the **Guided tour** card at the top of the Demo panel (signed in as Kamran):

- **Present it**: seven chapters that move on by themselves while you talk. Pause and play are on the card.
- **Walk it yourself**: the client advances with **Next**, and the chapters that ask for an action wait until they do it. Finished chapters tick off, and the tour remembers where they got to.

The chapters are: An enquiry arrives → It's already assigned → Reply on WhatsApp → Turn it into a deal → Move it forward → Send the quote → The owner's view. The tour sends a real Instagram lead, has the student reply on WhatsApp from the same number, and spotlights the real controls. It is never a video.

The tour is demo-only. It cannot appear in a real workspace once the backend is live.

## Talking points for SBC

- **Lead leakage.** Facebook, Instagram and TikTok lead forms usually sit in Meta Business Suite or TikTok Ads Manager until someone exports them. Here they arrive in seconds, assigned, with the campaign attached. Rabia Anwar, who waited five days for a fee answer, is the lead SBC is losing today. The dashboard then shows which ads are worth paying for: 46 TikTok leads, zero files.
- **The 15-minute reply rule.** Every new lead gets a _Contact within 15 minutes_ task and a countdown the counsellor can't miss. The first-touch WhatsApp template is one click, even at night. The task closes itself when the counsellor replies.
- **Counsellor accountability.** Round-robin decides who owns each lead, not whoever grabs it. Every chat, call and note sits on the student's timeline, and the dashboard shows each counsellor's follow-up for the week. Conversations run on SBC's WhatsApp number, so when a counsellor leaves, the students stay with SBC instead of on a personal phone.
- **Intake-season visibility.** One board from New enquiry to Visa approved, with PKR totals per stage, a weighted forecast and flags on files that have gone quiet. January and September intakes stop being a spreadsheet chase.
- **PKR quotations with NTN and sales tax.** Itemised SBC fees, 16% Punjab sales tax, the NTN and the total in rupees and in words, with embassy and university fees clearly excluded. It goes to the family as a PDF on WhatsApp inside the 24-hour window, or by email.

## What is real and what is simulated

Be straight about this if asked. It is a strength, not a confession.

| Real today                                                                                                | Simulated today                                                                            |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Every screen, every rule, every total                                                                     | The leads and messages come from the Demo panel, not from Meta or TikTok                   |
| The lead pipeline: matching, round-robin assignment, 15-minute tasks, conversion                          | WhatsApp delivery ticks are played back by the simulator, not by Meta                      |
| Pakistan details: PKR, 16% sales tax, NTN, SECP numbers, provinces, SEZ / EPZ, +92 mobiles, Pakistan time | Channel connections in Settings show a demo connect flow (TikTok shows "pending approval") |
| The 24-hour WhatsApp window and template rules                                                            | Sign-in is a user picker (real sessions arrive with the backend)                           |
| The API contract and data model that the real backend implements                                          | The spreadsheet import writes to the browser, not a server                                 |

**The next phase** wires the same screens to a real server and the official WhatsApp Cloud API, using Meta's test number first. Nothing on screen is thrown away. The screens only know the API contract, so they switch to live data without a redesign.

| ------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Numbers look stale ("5 days ago" on a fresh lead) | Demo panel → **Reset demo data**                                                   |
| Hamza's window doesn't update live                | Make sure both windows are in the same browser (live updates are per browser)      |
| The first live lead went to Mahnoor or Usman      | Round-robin moved on. Open that counsellor's window from **Rep windows**, or reset |
| **Send on WhatsApp** is blocked                   | That student hasn't written in 24 hours. Use Ali Raza's deal, or **Send by email** |
| A page looks empty                                | Reload it. If it persists, reset the demo data                                     |
| You lost the counsellor window                    | Demo panel → **Rep windows** → **Open window** next to Hamza                       |
